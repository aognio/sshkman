sshkman

sshkman

sshkma and sshkmad form a self-hosted, zero-knowledge SSH identity vault with OpenSSH provisioning. The server stores ciphertext and public cryptographic parameters only. The client owns vault passwords, key derivation, and unwrapping.

This site holds long-form manuals and guides. The Rust API reference lives on docs.rs/sshkman.
